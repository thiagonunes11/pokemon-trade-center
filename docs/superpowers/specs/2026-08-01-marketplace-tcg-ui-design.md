# Marketplace TCG UI — Design Spec

**Date:** 2026-08-01  
**Status:** Approved (supersedes editorial direction for visual system)

## Goal

Replace the editorial “magazine” look with a **commercial Pokémon TCG marketplace** aesthetic: dark + Pokémon yellow, large set covers, strong CTAs. Keep progress folio, binder owned/missing, and PNG share.

## Locked decisions

| Topic | Choice |
|-------|--------|
| Vibe | Marketplace / storefront |
| Palette | Dark + Pokémon yellow (`#FFCB05`) |
| Catalog | Hero set covers (1 col mobile, 2 desktop) |
| Approach | Full commercial reskin |
| Keep | Progress, binder mode, share PNG, link stub, light/dark/system |

## Tokens

- bg `#0B0D12`, secondary `#11141C`, card `#151822`, elevated `#1E2330`
- Light: paper `#F5F6FA`, cards white, text ink
- accent `#FFCB05`, accent-hover `#F5B800`, on-accent `#0B0D12`
- Fonts: Outfit (UI + titles), DM Mono (counts)

## Screens

- Catalog: hero covers with logo + ProgressFolio overlay/footer
- Set / Collection / Share: yellow primary CTAs; binder unchanged in behavior
- Shell: yellow active nav
- Login: bold brand + yellow submit
- Trades: commercial “coming soon” stub
